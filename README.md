# 📑 Manual QA, Test Planning & Agile Defect Management Portfolio

This repository showcases a complete, end-to-end manual software quality assurance lifecycle for a Facebook platform clone. It bridges strategic test planning, rigorous test scenario formulation, and modern Agile defect tracking metrics.

---

## 📋 1. Master Test Plan

**Project:** Facebook Core Features Validation
**Approach:** Structured Manual Functional & Boundary Verification

### Strategy & Scope
* **In-Scope:** Verification of user authentication bounds (email/phone parameters), input validation logic, password masking behaviors, and account recovery link expirations.
* **UI/UX Testing:** Verification of critical interface layouts, text field visibility, and interactive button alignments across standard viewports.
* **Out-of-Scope:** Stress/load performance analysis and security penetration testing.

---

## 🔍 2. Manual Test Case Design & Coverage

Before executing scripts, a comprehensive requirement breakdown was conducted to isolate functional dependencies, edge cases, and missing parameters.
* **Total Manual Scenarios Documented:** 66 Scenarios.
* **Core Modules Evaluated:** Multi-step registration validations, authentication restrictions, element presence layouts, and system error messaging.
* **Artifact Download:** Review and download the full operational execution sheet directly: [qa_fbmanual.xlsx](qa_fbmanual.xlsx).

---

## 🛠️ 3. Agile Project Management & Defect Tracking (Jira)

The testing execution lifecycle was strictly managed using **Atlassian Jira** cloud infrastructure to mirror professional production team environments:
* **Sprint Executions:** Managed active sprint workflows to handle backlog grooming, balance task velocity, and structure verification flows.
* **Defect Management:** Formulated comprehensive bug logs detailing step-by-step reproduction flows, explicit actual vs. expected variances, and clear impact severities.
